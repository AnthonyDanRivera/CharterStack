# API

REST API under `/api/`, built with Django REST Framework. JSON in and out. Session authentication (cookie) with CSRF protection. Every endpoint except `demo-login` and `health` requires a logged-in demo user and only ever returns that user's data.

Interactive docs are generated by drf-spectacular at `/api/docs/` (Swagger UI) and `/api/schema/`.

Conventions:
- Dates: `YYYY-MM-DD`. Times: `HH:MM` 24-hour. Null time = not set (or One way for `return_time`).
- Money: decimal strings, `"1200.00"`.
- Validation errors: HTTP 400 with `{"field": ["message"]}`; non-field errors under `"non_field_errors"`.
- Not found, or belongs to another sandbox: HTTP 404 (never 403, so IDs do not leak).
- Throttled: HTTP 429.

## Session

### `POST /api/demo-login/`
Creates a demo user and sandbox, logs the browser in, returns the session info. No body. Throttled per IP (see `DEMO_SANDBOX.md`).

```json
{ "user": "Demo User", "session_id": "DEMO-8F3K2", "started_at": "2026-11-12T21:04:37-05:00", "server": "demo-server" }
```

### `GET /api/session/`
Returns the same object for the current session, or 401 when not logged in. The React app calls this on load to decide between the landing page and the app.

### `POST /api/logout/`
Ends the session. The sandbox is left for the cleanup job.

### `GET /api/health/`
`{"status": "ok"}`. For uptime checks.

## Reference data (read-only)

### `GET /api/reference/`
One call that returns everything the dropdowns need:

```json
{
  "terminals": [{ "code": "NJ", "name": "New Jersey" }],
  "drivers": [{ "id": 1, "name": "Marcus Bell", "phone": "(201) 555-0101" }],
  "buses": [{ "id": 1, "number": "4512", "seats": 56, "model": "MCI J4500", "has_wc_lift": false }],
  "size_options": ["56-pax coach", "56-pax coach WC"],
  "states": [{ "code": "NJ", "name": "New Jersey" }],
  "cities": { "NJ": ["Hoboken", "Union City"] }
}
```

### `GET /api/zip/{zip}/`
`{"zip": "07087", "city": "Union City", "state": "NJ", "county": "Hudson County"}` or 404.

## Contracts (Booking)

### `GET /api/contracts/`
Query parameters:
- `start`, `end` — date range; returns contracts whose begin–return span overlaps it.
- `status` — `all` (default), `active`, `booked`, `quote`, `cancelled`.
- `q` — search text (rule R28).

Response:
```json
{
  "results": [{
    "id": 31, "number": 24817, "status": "booked",
    "begin_date": "2026-11-09", "start_time": "07:15",
    "organization": "Union City Public Schools", "group_name": "9th Grade Biology",
    "pickup_city": "Union City", "dest_city": "Jersey City", "bus_count": 1,
    "total_price": "950.00", "balance_due": "950.00", "payment_status": "Unpaid"
  }],
  "summary": { "count": 12, "booked": 10, "quotes": 1, "cancelled": 1, "balance_due": "18600.00" }
}
```

### `POST /api/contracts/`
Creates a contract and its units (rule R14). The server assigns `number`. Body: every writable field of the contract detail below. Returns 201 with the detail.

### `GET /api/contracts/{id}/`
Full contract:
```json
{
  "id": 31, "number": 24817, "status": "booked",
  "organization": "Union City Public Schools", "group_name": "9th Grade Biology", "passengers": 48,
  "contact_name": "Ms. Alicia Gomez", "contact_phone": "(201) 555-0117",
  "begin_date": "2026-11-09", "spot_time": "06:45", "start_time": "07:15",
  "return_date": "2026-11-09", "return_time": "14:15",
  "pickup": { "location": "Union City High School", "address": "2500 Kennedy Blvd", "city": "Union City", "state": "NJ", "zip": "07087", "county": "Hudson County" },
  "destination": { "location": "Liberty Science Center", "address": "222 Jersey City Blvd", "city": "Jersey City", "state": "NJ", "zip": "07305", "county": "Hudson County" },
  "itinerary": "", "bus_count": 1, "terminal": "NJ", "size_requirement": "56-pax coach",
  "requested_driver": null, "info": "Driver checks in at the main office on arrival. No food or drink on the bus.",
  "total_price": "950.00", "deposit_required": "0.00", "total_paid": "0.00",
  "balance_due": "950.00", "payment_status": "Unpaid", "payment_tone": "warn",
  "units": [{ "id": 77, "display_number": "24817", "driver": null, "bus": null, "report_time": null, "actual_report_time": null, "confirm_initials": "", "confirmed_at": null, "dispatch_notes": "" }]

```
`payment_tone` is one of `ok`, `part`, `warn`, `none` and drives the text color.

### `PATCH /api/contracts/{id}/`
Partial update. Changing `bus_count` adds or removes units (rule R14). Returns the detail.

### `DELETE /api/contracts/{id}/`
Deletes the contract and its units. 204.

### `GET /api/contracts/next-number/`
`{"number": 24845}` — shown read-only in the insert form.

### `GET /api/contracts/lookup/?number=24823-2`
Resolves a typed number (digits, `D`, `-`) to a contract: `{"id": 35}` or 404 (rule R31).

## Board (Dispatch)

### `GET /api/board/`
Query parameters:
- `start`, `end` — date range (default today).
- `view` — `today` (default), `away`, `all` (rule R25).
- `terminals` — comma-separated codes; omitted = all; empty string = none (rule R27).
- `q` — search text. Applied to `rows` only, not to `counts`.
- `sort`, `dir` — optional column key and `asc`/`desc` (rule R30). The frontend may also sort client-side.

Response:
```json
{
  "counts": { "trips": 6, "need_driver_or_bus": 3, "pending_confirmation": 4 },
  "refreshed_at": "2026-11-12T21:04:37-05:00",
  "rows": [{
    "id": 77, "contract_id": 31, "display_number": "24817", "is_duplicate": false,
    "day_label": "1/1", "is_multi_day": false, "terminal": "NJ",
    "begin_date": "2026-11-09", "start_time": "07:15", "spot_time": "06:45",
    "report_time": null, "actual_report_time": null, "actual_report_late": false, "on_location_time": null,
    "organization": "Union City Public Schools", "group_name": "9th Grade Biology",
    "pickup": "Union City High School, 2500 Kennedy Blvd, Union City, NJ 07087",
    "destination": "Liberty Science Center, 222 Jersey City Blvd, Jersey City, NJ 07305",
    "return_date": "2026-11-09", "return_time": "14:15",
    "driver": null, "driver_phone": null,
    "bus": null, "bus_seats": null,
    "size_requirement": "56-pax coach", "needs_wc": false,
    "confirm_initials": "", "confirmed_at": null,
    "status": "", "dispatch_notes": ""
  }]
}
```
`status` is the effective status: `cancelled` when the contract is cancelled (rule R07).

### `GET /api/units/{id}/`
One unit with everything the Trip information and Assign panels need: the board row fields plus `passengers`, `contact_name`, `contact_phone`, `info`, `itinerary`, `requested_driver`, `bus_count`, and the unit's saved `driver`, `bus`, `report_time`.

### `PATCH /api/units/{id}/`
Updates dispatch fields. Any subset of: `driver` (id or null), `bus` (id or null), `report_time`, `confirm_initials`, `dispatch_notes`. The server normalizes initials and manages `confirmed_at` (rule R22). Response is the unit plus:
```json
{ "warnings": ["Bus #3108 seats 35; this group has 48 passengers."] }
```
Warnings never block the save (rule R18).

### `GET /api/units/{id}/check/?bus=6`
Returns the same `warnings` for a bus choice **before** saving, so the note can show as soon as the dropdown changes.

### Unit actions
All return the updated unit.
- `POST /api/units/{id}/reported/` — toggle actual report stamp (rule R19). Optional body `{"clear": true}` for the × button.
- `POST /api/units/{id}/on-location/` — toggle (rule R20).
- `POST /api/units/{id}/cancel/` — toggle (rule R21).
- `POST /api/units/{id}/duplicate/` — returns the **new** duplicate unit, 201 (rule R16).
- `DELETE /api/units/{id}/` — only for duplicates; 400 for regular units.

Stamps use the server clock converted to the visitor's time zone. The frontend sends its IANA time zone in an `X-Timezone` header (for example `America/New_York`); default is `America/New_York`.

### `GET /api/board/export.xlsx`
Same query parameters as `/api/board/`, plus `columns` (comma-separated column keys in display order). Returns an Excel file built with openpyxl: bold, frozen header row with auto-filter, column widths proportional to the board's, blank driver/bus/initials written as `Unassigned` / `Needed` / `Pending`. Filename `CharterStack-board-{start}.xlsx`.

Column keys: `contract, day, terminal, beginDate, startTime, reportTime, actualReport, spotTime, onLocAt, org, pickup, dest, group, driver, busNum, sizeReq, returnDate, returnTime, confInit, confAt, driverPhone, hasNotes, notesText`.
